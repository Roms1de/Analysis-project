# Data & Product Analytics Portfolio

Этот репозиторий содержит мои учебные и pet-проекты, связанные в первую очередь с **продуктовой и data-аналитикой**. В проектах я использую **PostgreSQL и Python**, анализирую пользовательское поведение, продажи и продуктовые метрики, а также применяю методы машинного обучения и статистического анализа.

Репозиторий постепенно дополняется новыми проектами.
